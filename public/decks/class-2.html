Everyone hits these

Three things that look scary, and are not.

A strange editor opened
You forgot -m. If it is Vim (full screen, no menus), quit with:
Esc:q!Enter
If it is Notepad: type a message on line 1, save, close. Next time use -m "message".
A warning about LF and CRLF
warning: LF will be replaced by CRLF
Normal on Windows. Windows and Mac end lines differently. Ignore it; your command worked.
"Please tell me who you are"
*** Please tell me who you are.
Git has no name or email yet. Run the two git config --global lines, then commit again.

All you need

Four commands to branch.

CommandWhat it does
git branch feature-branchCreates a branch. You do not move onto it.
git checkout feature-branchMoves you onto that branch. git switch also works.
git branchLists branches. * marks the one you are on.
git merge feature-branchBrings that branch's commits into the branch you are on.

Not every merge is a fast-forward

Three ways a merge can go.

Fast-forward
Just slide forward
Master did not move. Git moves the label. No new commit.
Three-way merge
Both moved
Different parts changed. Git makes a new merge commit joining both.
Conflict
Same lines changed
Git will not guess. It pauses and asks you to choose.

The stash family

Four stash commands.

CommandWhat it does
git stashPut unfinished changes in the drawer. Desk is clean.
git stash listSee everything in the drawer.
git stash popTake the newest one back out and remove it from the drawer.
git stash applyBring it back but keep a copy in the drawer.
