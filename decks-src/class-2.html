05 All you need

Four commands to branch.

CommandWhat it does

05 Not every merge is a fast-forward

Three ways a merge can go.

Fast-forward
Just slide forward
Master did not move. Git moves the label. No new commit.
Three-way merge
Both moved
Different parts changed. Git makes a new merge commit joining both.
Conflict
Same lines changed
Git will not guess. It pauses and asks you to choose.
TIME: 90 to 92 min. SAY: What we did is the simplest case, a fast-forward. When both branches have new commits in different places, Git joins them with a new merge commit, a three-way merge. When both changed the very same lines, Git stops and asks you. That is a conflict.

06 The stash family

Four stash commands.

CommandWhat it does
git stashPut unfinished changes in the drawer. Desk is clean.
git stash listSee everything in the drawer.
git stash popTake the newest one back out and remove it from the drawer.
git stash applyBring it back but keep a copy in the drawer.
TIME: 106 to 108 min. SAY: Pop takes it out and throws away the drawer copy. Apply brings it back and keeps a copy. You can stash more than once; list shows them all, and the newest is stash@{0}.
