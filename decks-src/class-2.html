All you need

Four commands to branch.

CommandWhat it does
git branch feature-branchCreates a branch. You do not move onto it.
git checkout feature-branchMoves you onto that branch. git switch also works.
git branchLists branches. * marks the one you are on.
git merge feature-branchBrings that branch's commits into the branch you are on.
TIME: 75 to 77 min. SAY: Four commands. branch creates, but does not move you. checkout moves you. branch on its own lists them; the star is where you are. merge brings another branch's work into the one you are standing on. TIP: The most common mistake: merging while standing on the wrong branch. Always check git branch first.

Not every merge is a fast-forward

Three ways a merge can go.

Fast-forward
Just slide forward
Master did not move. Git moves the label. No new commit.
Three-way merge
Both moved
Different parts changed. Git makes a new merge commit joining both.
Conflict
Same lines changed
Git will not guess. It pauses and asks you to choose.
TIME: 90 to 92 min. SAY: What we just did is the simplest case, a fast-forward. When both branches have new commits in different places, Git joins them with a new merge commit: a three-way merge. When both changed the very same lines, Git stops and asks you. That is a conflict.
When Git asks you to choose

A conflict is not a crisis.

=======
Hello and welcome, friend!
>>>>>>> feature-branch
1
Open the file

2
Keep the right text

3
Stage and commit
git add the file, then git commit.

TIME: 92 to 94 min. Concept only today; practice comes later. SAY: A conflict just means two people changed the same lines differently, and Git refuses to guess which you meant. Open the file. Between the arrows and the equals signs is your version; after it is the incoming one. Keep what is right, delete the rest and the three marker lines, save, add, commit. That is the whole process. The stash family

Four stash commands.

CommandWhat it does
git stashPut unfinished changes in the drawer. Desk is clean.
git stash listSee everything in the drawer.
git stash popTake the newest one back out and remove it from the drawer.
git stash applyBring it back but keep a copy in the drawer.
TIME: 106 to 108 min. SAY: Pop takes it out and throws away the drawer copy. Apply brings it back and keeps a copy. You can stash more than once; list shows them all, and the newest is stash@{0}.
